# 凍結した仮説(第 2 号)— 1 週間の折り返した最値を、抜けた側で取る

**2026-08-22 に凍結。作法 4(条件探しに使っていない銘柄)へ掛ける前に書いた。**

条件を変えたくなったら、それは**新しい仮説**として別に立て、別の確認機会
を使うこと。**同じ銘柄へ条件を変えて掛け直さない。**

## 条件

| 項目 | 値 |
| --- | --- |
| 入りの足 | M15 |
| 帯を引く足 | H1(エントリーの 2 つ上) |
| 帯の正体 | **直近 1 週間(H1 で 120 本)の最値** |
| 端の条件 | その最値で **折り返していること**(確定スイング) |
| 向き | **抜けた側**。上の端なら買い、下の端なら売り |
| 入り方 | 端そのものに逆指値。**終値での確認は待たない** |
| 損切り | 端から 1.5 ATR(M15 の物差し)、帯の内側 |
| 利確 | 置かない。240 本(2.5 日)で時間切れ |
| 時間帯 | UTC 21-22 時(NY 17 時のロールオーバー)は建玉を持たない |
| 同時保有 | 1 建玉 |
| コスト | 逆指値なので **入りも出も** スプレッド/2 + スリッページ |
| 道順 | **M1 で解く**(`intrabar="path"`)。ここを仮定すると符号が変わる |

対応する呼び出し:

    collect_fade_trades(
        m15,
        higher_minutes=60,
        zone_source="range", range_bars=120, range_needs_turn=True,
        entry_at_zone_extreme=True, edge_mode="break", break_confirm="touch",
        stop_buffer_atr=1.5, horizon=240, max_wait_bars=12,
        blocked_hours_utc=frozenset({21, 22}),
        intrabar="path", path_candles=m1,
    )

### 入れなかった機構と、その理由

| 機構 | 判定 | 理由 |
| --- | --- | --- |
| 終値で抜けを確認 | 捨てた | 4 銘柄中 3 つで悪化(USD/JPY +0.236 → +0.077)。確認を待つと値段が悪くなるぶんが、ダマシを避ける利得を上回る |
| 押し負け(安値切り上げ)で絞る | 捨てた | 選別として効かない。4 銘柄で 2 対 2 に割れる |
| 跳ね返り側と混ぜる(`edge_mode="auto"`) | 捨てた | 跳ね返り側がマイナスなので混ぜるだけ悪くなる |
| 反対側の端で決済 | 捨てた | 抜けた側から見ると損失方向 |

## 予想(掛ける前に書いておく)

**未使用銘柄での予想: 差引 +0.03 〜 +0.09 R、プラス銘柄 6 割前後。**

根拠と留保:

- 4 銘柄の +0.117 より下がると見る。条件(窓 120 本・損切り 1.5 ATR・
  保有 240 本)をこの 4 銘柄で選んでいるため
- ただし選んだ幅は広い。損切りも保有も掃引した全セルでプラスだったので、
  1 点に張り付いた選び方ではない
- **利益が右の裾から来ている**(勝率 14.8%、平均勝ち +6.79 R)。
  銘柄が変わると裾の出方も変わる。区間は広くなるはず
- クロス通貨はスプレッドが広く、コスト比率が上がる。損切り 1.5 ATR なら
  コストは R の 5〜10% 程度に収まる見込みだが、銘柄によっては 15% を超える
