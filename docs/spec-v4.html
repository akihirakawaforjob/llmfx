変更 2 / 3

出口は「ダウ転換」。転換したらドテン

利用者の説明
  1. 抵抗帯付近での指値は問題なし
  2. エントリーした帯から次の帯へ向かう勢いが落ち、ダウ転換サインを示した時点で、手じまいとし、成り行きで逆ポジションに入りたい。そのままブレイクしたら所謂激アツ。
  3. それでも、安値切り上げ、もしくは高値切り下げが継続するのであれば、逆ポジションの買い増しも視野。→激アツの継続。
売って走らせ、転換したら手仕舞って逆へ乗る 高値も安値も切り上がった時点で転換とみなす
ここでダウ理論を使う意味

入り口ではなく出口で使う。既に含み益のある建玉を持ち続けるかの判断なので、外れても「伸びなかった」で終わる。入り口で使うと不利に選別されるが、出口なら毒にならない。

激アツ

ドテンした側が帯を抜けてそのまま走ったら、その全部が取り分になる。切り上げが続く限り買い増しも視野、という指定。図では 1 回だけ足してある。

変更 3 / 3

損切りは「1つ前」の高値・安値へずらす

利用者の説明 — ここが今回いちばん重要 僕の説明→安値切り上げ、高値切り下げに、併せて損切り位置も変える。
実際の実装→安値切り上げと高値切り上げが起きると、その位置に損切り来てしまい、少しのより戻しで損切りになってしまう。

正しくは、安値切り上げ、高値切り上げ時に1つ前の(ここが重要)安値、高値に損切位置をズラす。
売り(抵抗帯から下へ) 高値3 が出た時点で、損切りは 高値3 ではなく 高値2 へ
買い(支持帯から上へ) 安値3 が出た時点で、損切りは 安値3 ではなく 安値2 へ
なぜ1つ前でないといけないか

いちばん新しい折り返しはいまの値段のすぐ近くにある。そこへ損切りを置くと、トレンドが壊れていない普通のより戻しで刺さる。図の点線がそれ。

1つ前まで下がっている(上がっている)なら、そのより戻しでは刺さらない。刺さるときは本当に構造が壊れたとき。

見込み

建値移動が消えるので、いま抱えている弱点2つ(建値への依存・1 pips の窓)はそのまま無くなる。代わりに「ダウ転換をどの足で判定するか」が新しい急所になる。過去の測定では、エントリーと同じ足で構造を追うと、この手法がわざわざ座って待っている調整波そのものに引っかかった。

絵にする途中で決められなかったこと

ここを埋めてもらえれば実装に入れる。推測で埋めると、また 1mm ずれる。

①
エントリーは指値か、成行か 説明では「抵抗帯付近での指値は問題なし」。ただしいま動いていて数字が出ているのは成行のほう(帯を越えて戻って引けた足の、次の足の始値)。「問題なし」はいまの成行のままで良いという意味か、指値に戻すという意味か。 図では成行(いまの実装)で描いた
②
ダウ転換はどの足で見るか エントリーの M15 か、帯を引いた H1 か、さらに上か。ここで成績が桁で変わった前例がある。M15 で追うと調整波で必ず落とされ、上の足に預けると生き残った。 図では M15(エントリーと同じ足)で描いた
③
転換の合図は「高値と安値の両方」か、「片方」か 売りを閉じる合図として、安値の切り上げだけで足りるか、高値の切り上げも揃うまで待つか。片方だけなら早く出られるが、ダマシも増える。 図では両方揃った時点(H4 が H3 を上抜けた足)で描いた
④
ドテンした側の損切りはどこか 転換の起点になった安値(図の L3)の下か、それとも帯の外か。 図では L3 の下に置いた
⑤
買い増しは何回まで、どれだけ 切り上げが続く限り無制限か、上限を置くか。1回あたりの量は最初と同じか、減らすか。増やした分の損切りは1本にまとめるか、別々か。 図では1回だけ、同量、損切りは共通で描いた
