帯に来た時点では方向を決めない

いまの実装は、帯へ触れる前に売るか買うかを決めています。 仕様は「帯が何を示したかに従う」。この 1 行の差を図で確認します。

仕様

あなたの手順(CLAUDE.md より)

利用者
  1. 抵抗帯を見つける — 何度も試され、そのたびに押し戻されている水準
  2. 帯で待つ — 抜けた瞬間に飛び乗らない
  3. 帯が何を示したかに従う — 弾かれたら跳ね返りに乗り、抜けたら 抜けた側に乗る。帯に来た時点では方向を決めない
  4. 伸ばす — 固定の利確を置くとこの裾を切り落とす
実装との差 3 が入っていません。reverse_entry という設定で、 帯へ触れる前に向きが固定されています。 False なら必ず跳ね返りに賭け、抜けたら見送る。 True なら必ずブレイクに賭け、跳ね返ったら見送る。
場面 1

弾かれた場合 — 執行足が下へ折り返す

帯が跳ね返した帯 100.00 / ATR 0.10 / 執行 M15
訂正 / 利用者の説明 2026-08-29

跳ね返りとブレイクで、入り方の機構が違う

利用者 まず抵抗帯に向かう現在値を貼り続ける。抵抗帯に触れるギリギリになったら、 跳ね返り用の指値をその少し下に置く。つまり、そのまま抜けたら この指値は約定にならず、無意味に損切りをする必要がなくなる。 抜けたら一旦指値をキャンセルする。

抵抗帯をブレイクして抜けた後、高値切り上げ・安値切り上げが見えたら、 次の高値切り上げ・安値切り上げの 2 つ下の時間足の ダウ転換時にエントリー。損切りラインもいつもの。

ポイントは、ブレイクに向かう値を指値で上手く拾わないようにすること。
こちらの実装との差 上の 3 図(先に来たほうを取る)は、両側とも「執行足の直近の折り返しを抜けたら入る」 で揃えていました。実際の手法は跳ね返りとブレイクで機構が別です。 とくに跳ね返り側の水準が違います — 執行足の折り返しは帯から離れた場所に出るので、 入る位置が悪く、損切りまでの幅も広くなります。
跳ね返り側 1

帯の少し下に置く。折り返せば発動する

跳ね返った場合帯 100.00 / 注文 99.88 / ATR 0.10

帯へ届く直前に、帯の少し下へ売り注文を置きます。 値段が下に来ないと発動しないので、折り返したときだけ入る。 損切りは帯の外。

跳ね返り側 2

抜けたら発動しない。取り消す

抜けた場合同じ注文 99.88 / 発動せず
ここが要点 ブレイクに向かう値を拾わない。帯に置いた指値だと、 抜ける瞬間に必ず約定して、そのまま損切りへ運ばれます。 すでに通過した値に置けば、抜けるときは そもそも約定しない。無駄な損切りが構造的に発生しません。
訂正 — 取り消しはもっと後 上の図は「抜けた瞬間に取り消す」と描いていますが、これは誤りです。 注文はすでに通過した値にあるので、抜けている間はそもそも約定しません。 残しておいても損をしない。そしてダマシで戻ってきたら、そこで拾えます。

正しい取り消しの条件は、利用者の説明どおり 「抜けた後に高値切り上げ・安値切り上げが起き、抵抗帯が既に機能しなく なったと思われる状態」。構造が確定して帯が死んでから取り消します。
ブレイク側

抜けた後、構造ができてから、次の押し目で入る

ブレイク後の押し目高値切り上げ + 安値切り上げ を確認してから

抜けた瞬間には入りません。高値1 → 安値1 → 高値2 → 安値2 と 切り上がるのを見てから、次の押し目で 2 つ下の足のダウ転換で買い。 損切りはいつもどおり 1 つ前の安値(安値2)。

確認したいこと

数字を決めないと実装できない 5 点

1・2 どこに置くか 決まり:「自分が注文を置く値を、価格がすでに通過していること」。 これが定義です。帯へ向かう途中の、すでに通り過ぎた水準へ置く。 具体的な距離は掃引で決める
3 「抜けた」の判定 決まり: 抜けた後に高値切り上げ・安値切り上げが起き、 帯が機能しなくなったと判断できた時点。抜けた瞬間ではない。 注文はすでに通過した値にあるので、抜けている間は約定しない。 残しておけばダマシの戻りを拾える
4 跳ね返り側の損切り 要検証。約定位置が帯に近くなるので、 リスク幅は今よりかなり狭くなります。 同じ値幅がより大きな R になり、コスト比率も下がる
5 同じ帯で両方起きたら 要検証。利用者は裁量では一旦様子を見るが、 機械なら入ってもよいかもしれないとのこと。両方測る
掃引の作法 要検証が 3 つあります。軸を増やすほど、偶然プラスになるセルが出ます。 このプロジェクトはその形で 11 回崩れました。掃引は コストを抜いた全銘柄合算(段 1)で行い、 表が台地になっているか(隣のセルでも成立するか)を必ず見ます。 1 点だけ跳ねていたら採りません。

帯へ触れた後、執行の足が 安値1 を下抜けたところで売り。 損切りは帯の外。この動きは今の実装でも取れます (reverse_entry=False のとき)。
