# 凍結: GBP の癖か、手法か

2026-08-29 凍結。**数字を見る前に、条件と予想をここへ書く。**

## なぜこの仮説になったか

帯の指値だけ(第5版・`max_flips=0, max_adds=0`)を、条件探しに使って
いない 6 銘柄で作法 3 に掛けたら**通らなかった**。

    9,763 件  +0.0401 R  t=+1.96
    銘柄×月クラスタ  95%CI -0.018 〜 +0.101   0 をまたぐ
    月クラスタ       95%CI -0.028 〜 +0.110   0 をまたぐ

合計 +391 R のうち **+378 R(96.6%)が GBP/USD 1 銘柄**から来ていた。
そして条件探しに使った 4 銘柄でも、最良は **GBP/JPY(+0.324)** だった。

| 群 | 最良 | 期待値 |
| --- | --- | ---: |
| 条件探しに使った 4 | **gbpjpy** | +0.324 |
| 使っていない 6 | **gbpusd** | +0.225 |

**手元の GBP は 2 銘柄しかなく、その 2 つが両群の首位。**

GBP/USD 単独を月クラスタで組み直すと:

    path     +0.2251  t=+4.16  95%CI +0.068 〜 +0.389  0 をまたがない
    adverse  +0.2021  t=+3.74  95%CI +0.050 〜 +0.367  0 をまたがない
    3 分割   +0.501 / +0.083 / +0.092   符号は反転しない

**このプロジェクトで初めて作法 2 と 3 を両方の測り方で通った。**
ただし 6 銘柄の中から見てから選んでいるので、選択の補正を掛けると:

    path     99.17%CI +0.021 〜 +0.450  0 をまたがない
    adverse  99.17%CI -0.001 〜 +0.423  **0 をまたぐ**

**厳しいほうの測り方では、補正するとぎりぎり落ちる。**

## 何を確かめるか

条件は **1 文字も変えない**。銘柄だけを足す。

    GBPAUD  GBPCAD  GBPCHF  GBPNZD  EURGBP

**この 5 銘柄は一度も触っていない。**条件探しにも、作法 1〜3 にも
使っていない。開発用(2000-2019)で 1 回だけ測る。
**検証用データ(2020 年以降)には触らない。**

条件(`tools/bootstrap_zone_only.py` の BASE そのまま):

```
zone_minutes=240, structure_minutes=60, range_bars=120,
zone_entry="exec_turn", zone_wait_bars=24, zone_entry_max_atr=2.0,
entry_signal="exec", entry_fill="level", entry_fallback="structure",
stop_basis="band", stop_buffer_atr=1.5, min_stop_atr=2.0,
reversal_signal="both", max_flips=0, max_adds=0, max_open=4,
blocked_hours_utc={21,22}, reverse_entry=True
```

`path` と `adverse` の**両方**で出す。片方だけ通っても通ったことに
しない。銘柄は混ぜず、R/月 を必ず出す。

## 予想(数字を見る前に書く)

| | 予想 |
| --- | --- |
| GBP 4 銘柄(GBPAUD/CAD/CHF/NZD) | **+0.05 〜 +0.15 R、4 銘柄中 3 つ以上がプラス** |
| EUR/GBP | **ゼロ付近(-0.05 〜 +0.05)** |

EUR/GBP を分けるのは、**GBP の癖なら GBP が主役の銘柄で出るはず**で、
EUR/GBP は値幅が最も狭い銘柄だから。ここまで揃って出たら
「GBP だから」ではなく「たまたま」を疑う側の材料になる。

**今回は「通らない」と予想する。**理由:

1. **2 銘柄から立てた仮説である。**GBP が 2 つしか無い中で 2 つとも
   首位、というのは「4 銘柄中 2 つが上位 2 つ」と大差ない
2. **効いている期間が偏っている。**GBP/USD の 3 分割は
   +0.501 / +0.083 / +0.092。2000-2007 が 5 倍以上ある
3. **これまで 11 回、同じ形で崩れた。**標本の中で条件(今回は銘柄)を
   探し、良い数字が出て、標本を広げると消える

外すとしたら、GBP の値幅の広さがコスト比率を下げている、という
機構が本物だった場合。GBP クロスはスプレッドも広いので、
**そこが相殺されるかどうかが分かれ目**になる。

通らなかったら、帯の手法はここで打ち止め。
