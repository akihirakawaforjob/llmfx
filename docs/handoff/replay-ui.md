# リプレイ画面(`docs/replay.html`)

利用者がコマンドを使わずに、足を流しながら場面へ印を付けるための画面。
**印は「引く / 引かない」の教師データになる。**

## 何が入っているか

- USD/JPY と GBP/JPY の 15 分足、2016-01 〜 2018-12(各 74,539 本)
- 時刻と価格を差分の整数で持たせて 2.4MB に収めた(`tools/build_replay_data.py`)
- 帯・指値・損切りの計算は **JS で書き直した簡易版**。ATR は単純移動平均
  なので Python 側(Wilder)とは厳密には一致しない。
  **目で見るための道具であって、測定はこちらでやらない。**

## 印に入るもの

    銘柄 / 時刻 / 位置(足番号)/ 価格 / ひとこと
    設定(帯の作り方・窓・まとめ幅・要求する折り返し・弾き・向き・指値・損切り)
    見えていた線(足ごとの帯の値段と、注文の指値・損切り)

**「なぜそう思ったか」を書かなくても、こちらの線と利用者の判断のずれは測れる。**
印は `localStorage` に残るので、閉じても消えない。

## 受け取ったあとにやること

1. 印の `位置` から、その時点の実データを取り直す
2. 印が付いた場面と付かなかった場面で、こちらが引いた線の何が違うかを数える
3. 差が出たら、それを条件として実装して作法 1〜4 に掛ける
